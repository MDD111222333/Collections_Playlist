# C_Sharp_Collections_Playlist

## C#_Collections_Playlist

### Задание «Контрольная точка №32 — LinkedList<T>»

Вариант 1. Плейлист
1. `LinkedList<string>` playlist с несколькими названиями песен, добавленными через AddLast.
2. Метод `PlayNext(string song)`, добавляющий песню сразу после текущего узла «играет сейчас» (храните ссылку на этот узел отдельно) — то есть песня встаёт в очередь следующей, а не в конец плейлиста.
3. Метод поиска песни по названию через Find, с проверкой на null.
4. Метод удаления песни по названию через Remove.
5. Продемонстрируйте обход всего плейлиста через foreach до и после операций из пунктов 2 и 4.
